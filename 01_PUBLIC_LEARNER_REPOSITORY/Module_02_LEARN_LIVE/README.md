## 🌟 Overview

Reading a document is only one way to learn from it. With a source-based AI notebook, the same material can become a concise summary, a sequence of questions, a visual mind map, flashcards, an audio discussion, or a presentation. This module explores those possibilities through one accessible project: **Stay Smart in the Digital World**.

The sources are about digital safety, a topic relevant to students, teachers, researchers and working professionals. They include intentionally fictional scenarios alongside external published guidance. Source-based AI responses help with understanding, **but citing a document does not guarantee that the document itself is correct**.

## 🎯 Learning objectives

After exploring this module, you should be able to:

- Import and combine different kinds of learning sources into one notebook.
- Ask questions that draw upon the uploaded material and inspect supporting citations.
- Generate or request summaries, maps, assessments and creative learning outputs.
- Recognise the distinction between **dedicated Studio outputs** and **outputs requested through Chat instructions**.
- Distinguish evidence, examples and uncertainty when an AI combines multiple references.

## 📥 What can Gemini Notebook accept?

Depending on current product support and account eligibility, possible sources include PDF, DOCX, PPTX, TXT, Markdown, CSV, images, audio, website URLs, captioned public YouTube videos, pasted text and supported Google Workspace documents. File-size, document-length, language and source-count limits can vary.

For supported formats and updated restrictions, consult [Google's official Notebook help](https://support.google.com/notebooklm/). The project deliberately uses **PDF + DOCX + PPTX + TXT + YouTube + Webpage**, so you can understand how a mixed-source notebook works.

## 🧪 Practical walkthrough — From sources to understanding

### Step 1 — Create your notebook

1. Open [Gemini Notebook](https://notebook.google/) and sign in with an eligible Google account.
2. Create a notebook titled **Stay Smart in the Digital World — Learning Lab**.
3. Add the four local source files using the source-import controls.
4. Add the FTC webpage, then attempt the CISA video where supported.
5. Review the imported source names and make sure the text was interpreted correctly.

### Step 2 — Understand and summarise

Copy into the notebook chat:

```text
Using the selected sources, explain the most important digital safety habits
under four headings: Recognise, Protect, Verify and Respond.
Give six concise takeaways and identify the supporting source for each.
Clearly label fictional case examples and flag unsupported claims.
```

Compare the generated summary with the PDF and the published webpage. Look for distinctions between *practical advice* and *fictional teaching scenarios*.

### Step 3 — Ask a question and inspect citations

```text
According to the Digital Safety Fundamentals PDF and the FTC webpage,
what should someone do after receiving an unexpected account-verification link?
Explain the safe response step by step, cite supporting passages,
and state any uncertainty or missing information.
```

Open at least one returned citation. Does the source genuinely support the answer? If a source is missing, ask the model to identify the limitation instead of inventing details.

### Step 4 — Convert the sources into different learning formats

Gemini Notebook may provide dedicated controls for several formats. Choose the relevant output in its Studio panel and use optional **customisation instructions** where available. For some formats—especially custom MCQ banks and glossaries—the prompt belongs in notebook **Chat** rather than a dedicated Studio tile.

| Output | What it provides | How to explore it |
|---|---|---|
| 🧠 Mind Map | Visual branches and concept relationships | Generate from selected sources; open and expand meaningful branches |
| 📝 Quiz | Interactive knowledge checks | Choose available quiz settings or tailor the quiz description |
| 🗂️ Flashcards | Quick question–answer revision | Focus on key concepts and common misconceptions |
| 🎧 Audio Overview | Spoken explanation or discussion | Choose the available format, focus and language settings |
| 🎬 Video Overview | Narrated visual explanation | Focus on important source-grounded ideas |
| 🎨 Infographic | Condensed visual summary | Use a single theme, short labels and a clear takeaway |
| 📊 Slide Deck | Structured presentation | Specify the audience, explanation depth and core message |
| 📑 Report | A structured written synthesis | Specify headings, evidence expectations and relevant limitations |
| 💬 Source-grounded Q&A | Answers with supporting passages | Ask in chat, inspect references and challenge weak conclusions |
| 📄 Source Summaries | Concise explanations of one or more documents | Summarise in chat or use the relevant summary view |
| ✅ MCQ Question Bank | Multiple-choice practice with explanations | Ask for an MCQ bank in chat |
| 📖 Glossary | Definitions of important terms | Ask for an alphabetised glossary in chat |

**Important:** Availability and the exact editing controls vary by account and product version. Not every listed output is a separate one-click feature. Some generation tasks can require processing time.

### Step 5 — Copy-ready instructions for selected outputs

**Quiz** — use the quiz customisation field where available:

```text
Create a beginner-friendly practice quiz about phishing, password safety,
privacy and verification using only the selected sources. Include explanations
and avoid treating fictional case studies as verified real incidents.
```

**Flashcards** — use the flashcard settings or customisation field:

```text
Make 12 short revision flashcards covering the most important digital-safety
terms and decisions in these sources. Each answer should be concise and clear.
```

**Audio Overview** — use the Audio Overview customisation field:

```text
Create a warm, conversational overview for curious beginners.
Explain how to recognise suspicious messages and verify requests safely.
Use clear everyday examples, avoid sensational claims, and acknowledge
which stories in the source pack are fictional.
```

**Video Overview** — use its focus/customisation controls:

```text
Create a clear visual explanation of the most useful online-safety habits.
Organise the story into recognising warning signs, checking a message,
protecting accounts, and taking sensible next steps. Ground the content
in the supplied sources and avoid unverified statistics.
```

**Infographic** — use the available visual customisation controls:

```text
Create a landscape infographic titled "Pause • Check • Protect".
Use one central concept, 6 short content blocks, large readable labels,
a simple decision flow, one worked example and a clear bottom takeaway.
```

**Slide Deck** — use its customisation controls:

```text
Create a concise, professional slide deck for a general audience explaining
how to recognise suspicious messages, protect accounts and verify claims.
Use large readable text, simple examples and a final checklist.
```

**Report** — use the report generator or an appropriate Chat instruction:

```text
Write a structured, source-grounded digital-safety briefing with headings:
Overview, Common Risks, Practical Safeguards, Fictional Case Lessons,
Evidence and Limitations, and Key Takeaways.
```

**Custom MCQ bank** — use notebook Chat:

```text
Create 8 beginner-friendly multiple-choice questions based only on the
selected sources. For each, provide options A–D, one best answer, a brief
explanation and a supporting citation. Label fictional scenarios clearly.
```

**Glossary** — use notebook Chat:

```text
Produce an alphabetical glossary of 12 digital-safety terms from the
selected sources. Give one plain-English definition, one everyday example
and a source reference. Omit unsupported terms.
```

For the **Mind Map**, standard generation may not provide the same dedicated free-text customisation input as other Studio artifacts; select the desired sources and explore the result.

## ✅ Learning and quality check

- Do summaries and reports distinguish fictional examples from external published guidance?
- Do the citations lead to relevant passages, rather than merely mentioning source names?
- Are question answers defensible from the selected documents?
- Is the audio or video overview understandable to somebody unfamiliar with the topic?
- Are graphical outputs legible when projected or viewed on a phone?
- Did an output introduce a claim that no supplied source actually supported?

## 🛡️ Privacy and practical boundaries

Use sample materials or documents you are authorised to upload. Avoid submitting passwords, confidential workplace documents or third-party personal information. Source-grounded answers can still be wrong, and a source citation is not independent fact-checking. Confirm important claims with reliable original sources.

The prepared files above are **input materials**. A populated Gemini Notebook, generated podcast, video overview and other Studio outputs are **not included as downloadable artifacts in this folder**; create and review them in your own account.
