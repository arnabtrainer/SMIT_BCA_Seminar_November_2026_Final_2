## 🌍 Overview

Artificial Intelligence (AI) already influences how we find information, navigate routes, discover content, communicate across languages and solve problems. This module introduces these experiences in accessible language—no programming background is necessary. It also introduces **prompting**, the skill of describing a task clearly so an AI assistant can respond usefully.

**The central idea:** AI is an assistant for human understanding and action, not an automatic guarantee of truth.

## 🎯 Learning objectives

After exploring this module, you should be able to:

- Recognise several everyday examples of AI-enabled systems.
- Explain the relationship among **AI**, **Machine Learning (ML)** and **Generative AI** in simple terms.
- Distinguish a vague request from a more useful, contextual AI prompt.
- Identify situations where an AI-generated answer needs independent verification.
- Understand the programme's practical progression: **Discover → Learn → Create → Build → Reflect**.

## 🧪 Practical activity — A familiar problem, explained clearly

An **algorithm** is a sequence of steps used to solve a problem. You do not need to write code to understand the idea. Consider planning a one-day trip: there is a destination, a budget, transportation, activities and information to check.

### A vague request

```text
Explain algorithms.
```

### A clearer, more useful request

Copy this into an AI chat application such as [ChatGPT](https://chatgpt.com/):

```text
Explain the idea of an algorithm to someone with no programming background.
Use the familiar example of planning a one-day trip.
Give:
1. Four sensible steps in the right order.
2. A one-sentence definition of an algorithm.
3. One question about what could go wrong if an important step is skipped.
Use simple English. Do not include code. Keep the reply under 100 words.
```

### Explore the response

1. Read the four steps. Are they in a sensible order?
2. Identify what the AI understood about the audience and required format.
3. Suggest one missing consideration such as budget, weather, transit availability or accessibility.
4. Ask a follow-up question to improve the result without rewriting everything.
5. Check any *current* factual claims—such as transport schedules or opening hours—against an official source before acting.

### Optional follow-up prompt

```text
Improve the plan by adding a short checklist of facts I should verify
before making a real booking. Do not invent live prices, schedules or
availability. Identify any missing information you would need from me.
```

**Expected result:** A simple explanation of an algorithm, a structured mini-plan and an understanding that fluent writing is not the same thing as verified information.

## ✍️ A practical prompt-writing pattern

| Ingredient | Useful question |
|---|---|
| **Task** | What should the assistant actually do? |
| **Context** | What situation or constraints should it consider? |
| **Audience** | Who is the explanation or output for? |
| **Format** | Should it return a table, steps, bullets or an example? |
| **Verification** | What should be checked, cited or labelled uncertain? |

**Try another scenario:** Replace the day trip with a job interview, a personal budget, a beginner science explanation or an office task. Keep the same prompt structure.

## 🛡️ Limits and responsible use

- AI models may produce confident but incorrect statements, invented references or incomplete answers.
- Recommendation, navigation and generative-chat systems are different kinds of technology; not every digital feature needs AI.
- Do not paste passwords, private financial data, confidential company files or another person's personal records into an unfamiliar service.
- Review AI-generated code, documents and decisions before relying on them.
- Follow academic-integrity, copyright, consent and organisational policies.
