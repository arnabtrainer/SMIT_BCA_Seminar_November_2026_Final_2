> **Our approach:** Discover what AI can do. Learn from trustworthy sources. Create with imagination. Build useful solutions. Reflect, verify and improve.

---

## 🌟 Welcome

Artificial Intelligence is more than a chatbot or an automated writing tool. It can help us understand unfamiliar ideas, explore reference materials, produce multimedia content and prototype applications. The greatest value comes when we combine AI capabilities with **human curiosity, creativity, critical thinking and responsible judgement**.

This programme follows five connected modules. Each has an independent learning guide, practical examples and links to its available resources. **No prior experience with AI or programming is required** to begin the core activities.

### 🎯 What you can achieve

- 🤖 Recognise AI in everyday life and write clearer, more effective prompts.
- 📚 Explore documents, websites and other references using source-based AI learning.
- 🎬 Plan an advertisement and understand the workflow for generating video, narration and music.
- 🛠️ Create, test and improve a simple application using natural-language instructions.
- 🧠 Check your understanding and discover opportunities for further exploration.

## 🚀 Getting started independently

1. **Start with [Module 1](Module_01_DISCOVER_LIVE/README.md)** for the foundations, even if you have never used an AI tool.
2. **Follow each module README in sequence** and open its linked *audience* slides or example source files when helpful.
3. **Try the copy-ready prompts and activities** using your own non-sensitive example materials. Compare the results with the original information.
4. **Test and refine outputs** rather than assuming that the first result is correct or complete.
5. **Explore [the glossary](AI_in_Action_Glossary.md)** whenever a new term is unfamiliar; finish with the [Module 5 knowledge challenge](Module_05_REFLECT_LIVE/README.md).

A supported browser and access to the relevant AI services are sufficient for many exercises. The offline Smart Planner can be downloaded as a single HTML file and run locally without a paid API or server.

## 🛡️ Use AI responsibly

- **Verify important claims.** An accurate-sounding answer is not proof; check the underlying source.
- **Protect privacy.** Do not upload passwords, personal records or confidential organisational materials without appropriate authorisation.
- **Respect authorship and permissions.** Confirm rights to use images, product marks, voices, music and recordings.
- **Distinguish concepts from reality.** AI-generated illustrations and independent promotional exercises should not be presented as authentic events or officially endorsed advertisements.
- **Test software.** Review inputs, calculations, stored data and user interactions before depending on an AI-assisted application.
- **Use your judgement.** AI can support creative and practical work, but responsibility for the final result remains with the person using it.
